# tests/ci-allowlist.txt — bats files that run in GitHub Actions (public sanity).
#
# GHA is the PUBLIC SANITY gate: only hermetic tests belong here — pure logic,
# temp-dir, or fully-mocked, with no dependency on live services, PostgreSQL,
# Redis, the Keychain, or network endpoints. Within these files, any individual
# env-dependent test either self-skips when its dependency is absent
# (`_pg_up || skip`, `_ai_up || skip`, `redis-cli ping || skip`, `launchctl ... || skip`)
# or is gated with `skip_in_ci` (skips when $CI is set).
#
# The LOCAL pipeline (bin/check / make check / make test) runs the FULL suite —
# including the live-platform e2e tests not listed here (currently platform_e2e).
#
# A file earns its place here only after being verified green under BOTH:
#   CI=1 ZDOTS_SKIP_ENV_TESTS=1 bats tests/<file>                       # services up
#   CI=1 ZDOTS_SKIP_ENV_TESTS=1 PGHOST=/dev/null ZDOTS_AI_ENDPOINT=http://127.0.0.1:9 bats tests/<file>   # deps down
#
# One filename per line (relative to tests/). Blank lines and # comments ignored.
