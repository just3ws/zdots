# Zdots

My Zsh dotfiles.

## Installation

```shell
cd
mv -f .zshenv .zshenv.bak
mkdir -p ~/.local/share/zsh
git clone git@github.com:just3ws/zdots.git ~/.config/zsh
ln ~/.config/zsh/.zshenv ~/.zshenv
exec "$SHELL"
```
